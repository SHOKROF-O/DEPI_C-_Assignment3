# Assignment 3 - C#

ASP.Net Course

## Questions

1. Check if a number is divisible by 3 and 4.
2. Check if a number is negative or positive.
3. Find the max and min of 3 integers.
4. Check if a number is even or odd.
5. Check if a character is a vowel or a consonant.
6. Print all numbers from 1 to n.
7. Print a multiplication table up to 12.
8. Print all even numbers from 1 to n.
9. Calculate the power of a number.
10. Calculate total, average and percentage of 5 subjects.
11. Print the number of days in a given month.
12. Simple calculator.
13. Reverse a string.
14. Reverse an integer.
15. Find prime numbers within a range.
16. Convert a decimal number to binary without using an array.
17. Check if 3 points lie on a single straight line.
18. Determine worker efficiency based on time taken.
19. Print an identity matrix of size n x n.
20. Find the sum of all elements of an array.
21. Merge two sorted arrays of the same size.
22. Count the frequency of each element in an array.
23. Find the max and min element in an array.
24. Find the second largest element in an array.
25. Find the longest distance between two equal cells.
26. Reverse the order of words in a sentence.
27. Copy a 2D array into another one and print it.
28. Print a 1D array in reverse order.

## Notes

Each question is a separate method (Q1 to Q28) in Program.cs.
Question 17 uses a separate Point class in Point.cs.
